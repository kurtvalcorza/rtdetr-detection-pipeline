# RT-DETR R50-VD real-time object detection pipeline

DIMER inference wrapper for **RT-DETR with a ResNet-50-vd backbone** (`PekingU/rtdetr_r50vd`), the real-time DETR from Baidu/Peking University trained on COCO 2017 (80 classes), pinned to an immutable Hugging Face revision and loaded only from a digest-verified local snapshot. The pipeline returns pixel-space boxes over the 80 COCO labels with the model's per-class sigmoid score under a caller-owned threshold; the vocabulary is closed (no text prompts) and no segmentation or tracking is provided.

## Upstream alignment

- Model: `PekingU/rtdetr_r50vd`
- Revision: `df939e661d8c52e80608d1ec566561aabd25a4e7`
- Upstream weight license: Apache-2.0
- Upstream task: object detection over the 80 COCO 2017 classes
- Repository adaptation: **none**; inference only

## Quick start

```python
from PIL import Image
from rtdetr_detection_pipeline import RTDetrDetectionPipeline

pipe = RTDetrDetectionPipeline.from_pretrained()   # stages + verifies weights/rtdetr-r50vd first
result = pipe.detect(Image.open("street.jpg"))     # any photograph; resized to 640x640 internally
for det in result["detections"]:                   # sorted by score, boxes are [x0, y0, x1, y1] pixels
    print(det["label"], det["box"], round(det["score"], 3))

# the threshold is the README example's value; override per call
result = pipe.detect(Image.open("street.jpg"), threshold=0.5)
```

Install into a Python 3.12 environment that already holds the pinned dependencies with `pip install -e . --no-deps`; run `pytest -q -o addopts= tests` for the offline test suite (no weights needed). On a fresh clone the manifest is committed but the weights are not: `RTDetrDetectionPipeline.from_pretrained(allow_download=True)` fetches exactly the missing manifest-listed files at the pinned revision, then verifies them.


## Input ceilings and threshold

`MIN_IMAGE_SIDE = 16`, `MAX_IMAGE_SIDE = 4096`, `MAX_DETECTIONS = 300` (the checkpoint's `num_queries`), `LABELS` (the 80 COCO classes in `id2label` order, upstream spelling — `motorbike`, `aeroplane`, `sofa`, `pottedplant`, `diningtable`, `tvmonitor`); `DETECTION_THRESHOLD = 0.3` (the pinned README example's value). One image per call; the processor resizes it to 640×640 without preserving the aspect ratio. See `MODEL_CARD.md` for who owns tuning the threshold, the sigmoid score semantics and the measured CPU timings.

## Tutorials

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/kurtvalcorza/rtdetr-detection-pipeline/blob/main/tutorials/rtdetr_detection_colab.ipynb)

`tutorials/rtdetr_detection_colab.ipynb` is declared `TASK-INFERENCE` / `GUIDED` under DIMER Notebook Specification 2.0 and is **standalone** (§4): generated by `tools/build_notebook.py`, it carries the pipeline module, model identity, manifest digests and runtime pins, so the exported notebook runs without this repository (parity enforced by `tests/test_notebook_parity.py`). Its default `Run all` path draws a 640×480 scene in code (a stop sign, a traffic light, an analogue clock and a sports ball; no download), surfaces the ceilings and the 80 labels, exposes the caller-owned `threshold` as a form parameter, resolves the pinned model through the carried staging and verification path, validates the request through `validate_inputs` into an input manifest, detects through `RTDetrDetectionPipeline.detect`, writes an `evaluation_report` whose per-object `box_iou` entries are sanity evidence only (`sample-sanity` with the drawn reference boxes keyed by COCO label — including the sports ball the model does not find — `not-measurable` without; no mAP), and exports JSON, a detections CSV and an annotated PNG. BYOD is optional and gated off by default. See `tutorials/README.md` for the registry and `docs/release-verification.md` for the release gate.
